Portfolio and professional site for **Aaron R. Davis** — journalist, investigator, and researcher.

- **Live site:** https://aaronrdavis.news
- **Dashboard:** https://dashboard.aaronrdavis.news

## About this repository

This is the source for my public portfolio. It includes case files, selected reporting clips, service information, and data-journalism prototypes built with HTML, JavaScript, and Cloudflare Pages.

Key pages:
- `/` — Main portfolio and services overview
- `/cases/dc-foia-plr/` — Public litigation record for *Tax Analysts v. District of Columbia*
- `/pi-services.html` — Investigative and litigation-support services
- `/stories/great-bay-eelgrass-collapse/` — Unpublished environmental investigation

## Deployment

Deployed to Cloudflare Pages via the Wrangler CLI.
